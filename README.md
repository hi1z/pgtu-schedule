# Расписание занятий — ПГТУ (УНИИТ)

Современный веб-интерфейс расписания занятий и звонков для студентов УНИИТ (ПГТУ — филиал НИУ МГСУ).

Выполнен в строгом минималистичном монохромном стиле (Black & White / High-Contrast Dark Mode) с повышенным контрастом, адаптивным просмотром по дням для мобильных устройств, отображением времени каждой пары прямо в сетке занятий и поддержкой PWA (работает офлайн).

## Возможности

- **Монохромная эстетика**: Глубокий черный фон, строгие контрастные акценты, швейцарская типографика, отсутствие аляповатых неоновых градиентов.
- **Информативная сетка расписания**: Время пар отображается сразу в заголовках (`I 08:30–09:50`), чтобы не нужно было переключаться во вкладку звонков.
- **Подсветка текущего момента**: Если сейчас идет пара или перерыв, в расписании и звонках отображается живой индикатор `● ИДЁТ СЕЙЧАС` (по времени GMT+3).
- **Мобильный режим с фильтром по дням**: На смартфонах доступен переключатель дней (`Пн`, `Вт`, `Ср`, `Чт`, `Пт`, `Все дни`), позволяющий смотреть расписание на сегодня компактными карточками без горизонтального скролла таблицы.
- **Звонки и часы**: Точная таблица пар и перерывов + аналоговые минималистичные часы и цифровой циферблат.
- **Рулетка выбора**: Колесо случайного выбора с вероятностями для сомневающихся.
- **PWA и офлайн**: Устанавливается как нативное приложение на Android, iOS и ПК; работает без доступа к сети через Service Worker.
- **Прямые ссылки**: Ссылки вида `#faculty=uniit&course=1&group=ii-26&week=auto&view=schedule` мгновенно открывают нужную группу и режим.

## Как запустить локально

Так как сайт полностью статический (Vanilla HTML/CSS/JS) без внешних зависимостей и сборщиков:
- Достаточно открыть файл `index.html` в любом браузере.
- Или запустить локальный сервер:
  ```bash
  python -m http.server 8080
  # или npx serve
  ```

## Как развернуть на GitHub Pages

1. Создайте новый репозиторий на GitHub (например, `pgtu-schedule`).
2. Привяжите удаленный репозиторий и запушьте код:
   ```bash
   git remote add origin https://github.com/<ВАШ_НИК>/pgtu-schedule.git
   git branch -M main
   git push -u origin main
   ```
3. В настройках репозитория на GitHub перейдите в **Settings → Pages**.
4. В разделе **Build and deployment** выберите:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` / `/ (root)`
5. Нажмите **Save**. Через 1–2 минуты сайт станет доступен по адресу `https://<ВАШ_НИК>.github.io/pgtu-schedule/`.

## Как обновить расписание

Все данные пар, групп, курсов и аудиторий находятся в файле `js/data.js`.
После изменения данных увеличьте версию кэша в `sw.js` (например, `pgtu-schedule-mono-v2`), чтобы Service Worker обновил кэш у всех пользователей.
