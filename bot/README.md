# Telegram-бот и синхронизация заметок ПГТУ

Этот сервер делает две вещи:
1. Отправляет напоминания за 5 минут до пары прямо в Telegram (работает даже при выключенном экране телефона).
2. Позволяет смотреть расписание, просматривать/добавлять домашние задания в боте и синхронизировать их с сайтом.

## Быстрый запуск (локально или на сервере)

Зависимости (`npm install`) **не требуются** — используется только стандартный Node.js (v18+).

1. Создайте бота в [@BotFather](https://t.me/BotFather) командой `/newbot` и получите `BOT_TOKEN`.
2. Скопируйте `.env.example` в `.env` (или передайте переменные окружения):
   ```bash
   BOT_TOKEN=ваш_токен
   BOT_USERNAME=имя_бота_без_собаки
   PORT=3000
   ```
3. Запустите сервер:
   ```bash
   node server.js
   ```
4. На сайте нажмите кнопку **Telegram** в шапке, вставьте адрес сервера (например, `https://your-bot.onrender.com` или `http://localhost:3000`) и нажмите **Войти через Telegram**.
